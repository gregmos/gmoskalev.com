Privacy Policy

Ymnky manager — a private Telegram bot and board for one band. Last updated 10 October 2026.

Ymnky manager is a private tool run by Grigorii Moskalev for the members of one music band. It is not offered to the public. This policy explains what data it uses and why.

What the app uses

  • Telegram data of band members who start the bot: Telegram user id, name, username, and the messages they send to the bot or to the band's group chat where the bot is a member.
  • Each member's Google email address, entered in the app so that meeting invitations can be sent to it.
  • Google Calendar events of the band's own Google account. With the calendar.events permission the app reads upcoming events and creates, updates and deletes events when a band member asks it to. It does not access email, contacts, Drive or any other Google data.

How it is used

Only to run the band's task board and to schedule the band's meetings: rehearsals, studio sessions, gigs and calls. Google sends the invitations and updates to the invited members itself.

Storage and sharing

Data is stored on the app's own server. The Google access token is kept in a file on that server and is never shown or logged. Data is not sold, not used for advertising, and not shared with anyone outside the band, except the service providers the app runs on (the server host and the language-model provider that interprets messages to the bot).

Google user data

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

The band's coordinator can disconnect Google Calendar at any time in the app's settings, which deletes the stored token; access can also be revoked at myaccount.google.com/permissions. A member can remove their email in the app or ask for any of their data to be deleted.
